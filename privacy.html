Política de Privacidade

Última atualização: 27 de Julho de 2026

1. Informações que Coletamos

  • Credenciais de API (armazenadas criptografadas via Infisical)
  • Configurações de canal e conteúdo
  • Logs de operações (para fins de debug)

2. Como Usamos Suas Informações

  • Para executar as automações solicitadas
  • Para melhorar o funcionamento do aplicativo
  • Para enviar notificações sobre o status das tarefas

3. Compartilhamento de Dados

  • Não compartilhamos dados pessoais com terceiros
  • Dados são compartilhados apenas com plataformas conectadas conforme necessário
  • Dados são armazenados localmente ou em serviços criptografados

4. Segurança

  • Usamos criptografia para dados sensíveis
  • Credenciais são armazenadas via Infisical (vault seguro)
  • Nunca logamos chaves de API ou tokens

5. Retenção de Dados

  • Dados são mantidos enquanto a conta estiver ativa
  • Logs são mantidos por 30 dias
  • Dados podem ser excluídos sob solicitação

6. Direitos do Usuário

  • Acessar seus dados pessoais
  • Solicitar exclusão de dados
  • Retirar consentimento a qualquer momento

7. Cookies e Rastreamento

Não utilizamos cookies ou ferramentas de rastreamento.

8. Menores de Idade

Não coletamos dados de menores de 18 anos. O aplicativo é destinado a usuários adultos.

9. Alterações

Esta política pode ser atualizada. Alterações serão publicadas nesta página.

10. Contato

Em caso de dúvidas sobre privacidade: https://github.com/canalinfantilprojeto
